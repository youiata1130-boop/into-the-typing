# ステージ3-1「キノコの森」

- 森エリア最初のステージ。内部IDは `mushroom_forest`。
- ステージ2-3「蜂群の草原」のクリアで解放。既存のクリア済みセーブにも対応する。
- 森のキノコ3体が1体ずつ登場。各HP12、攻撃16〜20、45EXP。合計135EXPはステージクリア時に保存する。
- 初回クリアで「片手剣」を獲得し、装備画面へ案内する。片手に剣・もう片手に盾を持ち、Spaceを押している間ガードする。以前の3-1クリア済みセーブにも報酬を補う。
- クリアで[3-2「胞子の小道」](spore-path.md)が解放される。初回は片手剣を装備して進み、報酬取得済みの場合はクリア結果から直接進める。
- キノコは右側の定位置から動かず、6秒溜めて胞子で攻撃する。攻撃後の360msの演出が終わると、次の6秒を開始する。
- 頭上に溜めゲージと「攻撃まで ○.○秒」を表示する。残り1.5秒で赤い表示と発光に変わり、攻撃時は「胞子攻撃！」と胞子の演出を表示する。動きを減らす設定でもゲージ・秒数・色の変化は表示する。
- 通常攻撃を受けている短い間は溜めを一時停止する。強撃を受けると溜め直す。いずれも位置は変わらない。
- 開始演出中、撃破後、終了後は攻撃しない。失敗・中断時の経験値とクリア記録は保存しない。

## 実装と検証

- ステージ設定: `src/config/stages.js` の `attackStyle: "charge"`、`chargeMs`、`fixedProgress`。
- 溜めと予告表示: `src/app/enemyCharge.js`。戦闘ループと同じ経過時間を使う。
- 自動テスト: `tests/integration/stages/mushroomForest.test.mjs`、`tests/integration/ui/stageMaps.test.mjs`。
- 画像と生成プロンプト: [森の素材](../assets/enemies/mushroom-generation.md)。
