# 4-1 鳥たちの山道

- エリア4は山道。3-4「荊の深森」クリア後に解放する。
- 青い鳥が右から主人公へ近づき、到達後は繰り返し攻撃する。海辺・草原と同じ移動型。
- 前半2羽: HP30、攻撃22〜28、接近10秒、再攻撃1.9秒、各80EXP。
- 後半3羽: HP36、攻撃26〜32、接近8.5秒、再攻撃1.7秒、各100EXP。
- 5羽を撃破し、大鳥から脱出するとステージクリアで460EXP。全敵撃破だけではクリアや報酬を確定しない。失敗・中断時はEXPを保存しない。

## 大鳥の捕獲

最後の5羽目の撃破演出後、大鳥が飛来して主人公を捕まえる一枚絵を3秒間表示する。絵の表示中は入力・ガード・スキルを受け付けず、制限時間も進めない。絵の表示が終わってから長文と残り25秒を表示し、全文を入力すれば脱出する。脱出演出が終わるとステージクリアになり、460EXPとクリア記録を保存する。時間切れはゲームオーバーで、全敵撃破済みでも報酬やクリア記録は保存しない。

一枚絵はステージ開始前に読み込む。画面の縦横比にかかわらず全体を収め、余白には同じ絵をぼかして表示する。絵の表示中に押したキーや入力文字は脱出入力へ持ち越さない。中断・再挑戦で表示タイマーも破棄する。[画像と生成プロンプト](../assets/enemies/mountain-capture-intro-generation.md)。

捕獲中は通常の敵を出さず、ガード・カウンター・スキルを使えない。入力は武器や素早さによって短縮されない。ミスをしても正しい入力部分は残るが、制限時間は戻らない。キーボードとフリック入力に対応し、句読点は入力不要。

長文は5種類をランダムな順で一巡させ、一巡するまで同じ文章を出さない。次の一巡の先頭も直前の文章と重複させない。出題履歴は捕獲開始時にブラウザへ保存し、再挑戦・失敗・ページ再読み込みでも続きを使う。ブラウザへの保存が使えない場合も、そのページ内では重複を避ける。進行度や経験値のセーブとは独立している。

再挑戦・画面移動では捕獲状態とタイマーを破棄し、再挑戦時は最後の敵を倒した後に再び捕獲が発生する。タイマー処理が遅れても、締切時刻以降の入力は成功扱いにしない。

## 使用文章と権利・出典

夏目漱石『草枕』第一章から、次の5つの一節を使用する（文字数は句読点を含む）。

| 一節 | 文字数 | 入力用の読み |
| --- | --- | --- |
| たちまち足の下で雲雀の声がし出した。 | 18 | たちまちあしのしたでひばりのこえがしだした |
| あの鳥の鳴く音には瞬時の余裕もない。 | 18 | あのとりのなくねにはしゅんじのよゆうもない |
| ただ菜の花を遠く望んだときに眼が醒める。 | 20 | ただなのはなをとおくのぞんだときにめがさめる |
| 雲雀の声を聞いたときに魂のありかが判然する。 | 22 | ひばりのこえをきいたときにたましいのありかがはんぜんする |
| 菜の花を見ても、ただうれしくて胸が躍るばかりだ。 | 24 | なのはなをみてもただうれしくてむねがおどるばかりだ |

- 原文: [青空文庫・草枕の本文](https://www.aozora.gr.jp/cards/000148/files/776_14941.html)
- 書誌・作者情報: [青空文庫・作品カード](https://www.aozora.gr.jp/cards/000148/card776.html)
- 初出: 『新小説』1906年9月。作者は1916年12月9日没。著作権保護期間が終了した原文を使用し、現代語訳や他者による翻案は使用していない。
- 青空文庫の底本: 『夏目漱石全集3』ちくま文庫、筑摩書房、1987年12月1日。入力: 柴田卓治、校正: 伊藤時也。
- 利用条件の確認: [青空文庫収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)（2026-10-24確認）。保護期間終了作品の複製・再利用が可能。出典をこの文書と捕獲中の作者・作品リンクに明示する。
- 原文のルビは本文から分離し、句読点を入力対象から除外する。音は原文のルビどおり「ね」、判然は「はんぜん」と読む。表示する原文の文言は変更していない。
