# 4-1 鳥たちの山道

- エリア4は山道。3-4「荊の深森」クリア後に解放する。
- 青い鳥が右から主人公へ近づき、到達後は繰り返し攻撃する。海辺・草原と同じ移動型。
- 前半2羽: HP30、攻撃22〜28、接近10秒、再攻撃1.9秒、各80EXP。
- 後半3羽: HP36、攻撃26〜32、接近8.5秒、再攻撃1.7秒、各100EXP。
- 5羽撃破で460EXP。捕獲による追加報酬はない。失敗・中断時は途中のEXPを保存しない。

## 大鳥の捕獲

前半2羽の撃破演出後、大鳥が主人公を捕まえる。画面に長文と残り時間を表示し、30秒以内に全文を入力すれば脱出して後半戦へ進む。時間切れはゲームオーバー。

捕獲中は通常の敵を出さず、ガード・カウンター・スキルを使えない。入力は武器や素早さによって短縮されない。ミスをしても正しい入力部分は残るが、制限時間は戻らない。キーボードとフリック入力に対応し、句点は入力不要。

脱出中の入力は次の敵へ持ち越さない。再挑戦・画面移動では捕獲状態とタイマーを破棄し、再挑戦時は再び捕獲が発生する。タイマー処理が遅れても、締切時刻以降の入力は成功扱いにしない。

## 使用文章と権利・出典

夏目漱石『草枕』第一章の一節（句点を含む18文字）:

> たちまち足の下で雲雀の声がし出した。

- 原文: [青空文庫・草枕の本文](https://www.aozora.gr.jp/cards/000148/files/776_14941.html)
- 書誌・作者情報: [青空文庫・作品カード](https://www.aozora.gr.jp/cards/000148/card776.html)
- 初出: 『新小説』1906年9月。作者は1916年12月9日没。著作権保護期間が終了した原文を使用し、現代語訳や他者による翻案は使用していない。
- 青空文庫の底本: 『夏目漱石全集3』ちくま文庫、筑摩書房、1987年12月1日。入力: 柴田卓治、校正: 伊藤時也。
- 利用条件の確認: [青空文庫収録ファイルの取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)（2026-10-24確認）。保護期間終了作品の複製・再利用が可能。出典をこの文書と捕獲中の作者・作品リンクに明示する。
- 入力用の読み: `たちまちあしのしたでひばりのこえがしだした`。原文のルビは本文から分離し、句点を入力対象から除外する。表示する原文の文言は変更していない。

文章データは `src/data/capturePassages.js`、捕獲処理は `src/app/mountainCapture.js`。
