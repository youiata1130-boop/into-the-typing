# ステージ3-2「胞子の小道」

- 森エリア2番目のステージ。内部IDは `spore_path`。3-1クリアで解放し、以前のクリア済みセーブからも挑戦できる。
- 3-1の初回報酬である片手剣を装備した後、そのまま3-2へ進める。ステージ選択からは他の所持武器でも挑戦できる。
- 前半は小道のキノコ2体。各HP14、攻撃18〜22、溜め5.5秒、50EXP。
- 後半は奥地のキノコ2体。各HP16、攻撃20〜24、溜め5秒、60EXP。
- 通常の4体を倒すと、最後にボス「キノコの王様」が登場。HP40、攻撃26〜32、溜め4.5秒、160EXP。王冠と紫のマントの専用画像、登場演出、通常より大きい表示枠を使う。
- 攻撃予告ゲージと状態ラベルは表示しない。オーラは溜めに応じて黄緑→黄→赤へ変わる。残り25％で専用の振りかぶり画像に切り替え、動きを減らす設定でも色と画像の切り替えを維持する。
- 合計380EXPをボス撃破後のクリア時に保存する。途中の失敗・中断・再開始では経験値とクリア記録を保存しない。武器報酬はない。
- 森の背景と通常キノコの既存画像を使用する。クリア後は[3-3「妖精の森」](fairy-forest.md)へ進める。[ボス画像と生成プロンプト](../assets/enemies/mushroom-king-generation.md)。

## 実装と検証

- 設定: `src/config/stages.js`。地図の地点: `index.html` と `src/styles/main.css`。
- テスト: `tests/integration/stages/sporePath.test.mjs`、`tests/integration/ui/stageMaps.test.mjs`、`tests/integration/progression/swordShieldReward.test.mjs`。

- 敵の溜め時間は各回の開始時に基準値の±10％で抽選する。オーラと振りかぶりは抽選後の時間に追従する。接近型の敵も接近時間と攻撃後の待機時間を同じ範囲で抽選する。
