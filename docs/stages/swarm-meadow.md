# ステージ2-3「蜂群の草原」

- 内部ID: `swarm_meadow`。2-2クリアで解放し、草原の地図に表示する。
- 通常の蜂12体の後、ボス「蜂の女王」が1体登場する。合計13体。
- 通常の蜂は同時最大4体。HP1、攻撃4〜6（2-2と同じ）、1体10EXP。
- 1体目は開始時に配置する。開始表示が消えてから600ms後に2体目を出し、以後も600ms間隔で1体ずつ出現する。接近時間10秒（2-2と同じ）、攻撃演出360msの後に900msで再攻撃。
- 蜂ごとに高さをずらし、4体とも主人公のそばまで移動する。それぞれ到着してから攻撃し、画像とHPは重ならないようにする。
- 通常の蜂を全て倒し、撃破演出が終わってから女王が単独で出現する。女王はHP12、攻撃18〜24、接近6.5秒、攻撃演出360msの後に1,800msで再攻撃。冠をかぶった専用画像を大きく表示し、ボス登場演出を使う。
- 女王の報酬は120EXP。女王を倒して初めてクリアとなり、ステージ合計240EXPを保存する。
- 双剣の短い入力と0.2秒のクールタイムで、1体ずつ素早く倒す多数戦。装備による入場制限は設けない。
- 比較テストでは到達時の515EXP、攻撃2・俊敏性2、同じ入力速度とスキル自動使用で比較する。PCは毎秒5文字、かなは350msごとに1文字、乱数3通りで双剣はクリアする。速度を下げた現在は鉄の剣でもクリアできる場合があり、双剣は鉄の剣以上の残HP・短い時間で攻略できる。プレイヤーの速度・成長・ミスによって結果は変わる。
- 2-2は鉄の剣・毎秒2文字でも攻略できることを検証している。
- 検証: `tests/integration/stages/swarmBalance.test.mjs`、`tests/helpers/swarmBalance.mjs`。
