# ステージ４「荒波の入り江」

- ステージ３「潮風の浜辺」のクリアで解放。大剣の装備案内を終えると「ステージ4へ」で開始。
- ステージ３をクリア済みのセーブデータでも解放。経験値や武器の所持だけでは解放しない。
- 敵: 魚２体（HP8、攻撃10〜16、各20EXP）、カニ２体（HP12、攻撃14〜18、各25EXP）、荒波のカニ王１体（HP24、攻撃16〜22、50EXP）。
- クリア時に合計140EXP。失敗・中断時は経験値やクリア記録を保存しない。
- 大剣・攻撃力2・ミスなしの場合は、魚各1回、カニ各2回、王3回の計9回の攻撃でクリア。
- 既存の海の背景、魚の泳ぎ、カニと王様カニの画像・演出を使用。
- マップの４番目の地点から選択でき、各プレイヤーの進行は独立して保存。
- 内部ID: storm_cove。
