# ステージ2-2「花咲く草原」

- 内部ID: `flower_meadow`。2-1クリアで解放する。
- 既存の鉄の剣で攻略する少数戦。蜂5体、HP1、攻撃4〜6、1体20EXP、合計100EXP。
- 1体目は開始時に配置する。開始表示が消えてから2,400ms後に2体目を出し、以後も2,400ms間隔。同時最大2体で、撃破演出中の敵も上限に含める。
- 主人公への接近時間は10秒。
- 追加出現しても入力中の敵を維持し、空いた表示位置を再利用する。
- 蜂ごとに主人公への到着を判定し、到着した個体だけが攻撃する。
- 初回クリアで双剣を獲得。装備画面で双剣を選び、2-3へ進める。失敗・中断・再挑戦では報酬を保存しない。
- 旧2-2クリア記録には双剣を補う。旧2-1だけのクリアには武器を与えない。
