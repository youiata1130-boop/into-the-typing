# ステージ3-4「荊の深森」

- 内部ID `thorn_depths`。森エリア、3-3クリアで解放。既存の3-3クリア済みセーブにも対応。地図と確認画面に「激ムズ」と表示する。
- 猛毒のキノコ2体: 各HP32、攻撃34〜42、基準溜め3秒、各90EXP。
- 狂樹の妖精2体: 各HP60、攻撃44〜52、基準溜め2.7秒、各160EXP。木の妖精の画像と木の葉の演出を共用する。
- ボス「荊冠の魔鹿」1体: HP144、攻撃64〜76、基準溜め2.2秒、600EXP。専用の通常姿、角を構える姿、荊の攻撃演出を使用する。
- 5体が1体ずつ登場する。3-3の総HP152に対して総HP328、ボスHPは2.4倍、ボスの基準攻撃間隔は約半分。能力の振り分け、速い入力、ガード、強撃による溜め解除が必要になる。
- 攻撃間隔は各回±10％。オーラはその回の溜め時間に合わせて黄緑→黄→赤に変化し、75％から構える。秒数と攻撃ゲージは表示しない。
- ガード時も本来の4分の1のダメージを受ける。大剣は入力途中にガードできない既存仕様を維持する。
- 合計1100EXPは全滅させた時だけ保存。失敗・中断時は破棄し、重複受領しない。新しい武器報酬はなく、クリア後は森の地図に戻る。
- 魔鹿の画像は3-4開始時だけダウンロードする。共通背景と既存の敵画像は再利用。

検証: 291件のテスト、構文チェック。攻撃7・俊敏性3・片手剣・1750EXPの合法な育成で、キー入力120ms間隔／フリック200ms間隔、3種類の乱数シードでクリアを確認。攻撃3・俊敏性2・キー入力400ms間隔ではガード・強撃を使っても途中で敗北する。PCと携帯の4画面サイズで地図、段階読み込み、ボス画像、構え、ガードを確認した。
