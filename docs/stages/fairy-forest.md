# ステージ3-3「妖精の森」

- 内部IDは `fairy_forest`。3-2クリアで解放。以前の3-2クリア済みセーブにも対応し、3-2のクリア結果から直接進める。
- 深緑のキノコ2体: 各HP22、攻撃22〜26、溜め4.5秒、60EXP。
- 古木のキノコ2体: 各HP24、攻撃24〜28、溜め4秒、70EXP。
- 最後にボス「木の妖精」1体: HP60、攻撃32〜38、溜め4.2秒、220EXP。全5体が1体ずつ登場する。
- 木の妖精は定位置で魔力を溜め、木の葉の嵐で攻撃する。専用の木の葉演出を使う。
- 攻撃予告ゲージと状態ラベルは表示しない。オーラは溜めに応じて黄緑→黄→赤へ変わる。残り25％で専用の振りかぶり画像に切り替え、動きを減らす設定でも色と画像の切り替えを維持する。
- ガード成功時のダメージは本来の4分の1にし、端数切り上げで最低1。通常被弾では溜めが短く停止し、強撃ではリセットされる。
- 合計480EXPは木の妖精を倒してステージをクリアした時に保存する。失敗・中断・再開始で途中の報酬を破棄する。武器報酬はない。クリア後は3-4「荊の深森」へ進める。
- 森背景を共用し、[木の妖精の専用素材](../assets/enemies/tree-fairy-generation.md)を追加した。

設定: `src/config/stages.js`。攻撃予告: `src/app/enemyCharge.js`。テスト: `tests/integration/stages/fairyForest.test.mjs` と `tests/integration/ui/stageMaps.test.mjs`。

- 敵の溜め時間は各回の開始時に基準値の±10％で抽選する。オーラと振りかぶりは抽選後の時間に追従する。接近型の敵も接近時間と攻撃後の待機時間を同じ範囲で抽選する。

- 難度調整: 総HPを124から152へ約23％増加し、攻撃間隔を約10〜16％短縮。3-4の総HP328・ボスHP144・基準溜め2.2秒より控えめにする。
