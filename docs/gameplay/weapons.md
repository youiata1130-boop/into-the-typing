# 武器と攻撃

| 武器 | 俊敏性1でのクールタイム | 通常攻撃の対象 | 入力・威力 |
| --- | --- | --- | --- |
| 木の枝 | 0.22秒 | 1体 | 2〜3文字、攻撃力×0.2 |
| 鉄の剣 | 0.7秒 | 1体 | 通常の短い単語、攻撃力×1 |
| 大剣 | 1.5秒 | 1体 | 基本12〜20文字、溜めにより最大×4 |
| 双剣 | 0.2秒 | 1体 | 基本2〜4文字、×0.6（整数に丸め最低1） |
| 片手剣 | 0.7秒 | 1体 | 鉄の剣と同じ文字数・威力、盾でガード可能 |
| 素手 | 0.48秒 | 1体 | チュートリアルの1〜2文字 |

- `src/config/weapons.js` の `attackCooldownMs` と `attackTargets` で武器ごとに設定する。敵の被弾演出 `attackRecoveryMs` と攻撃アニメーション `attackAnimationMs` は独立している。
- ステージ開始時に、武器の基準時間×（俊敏性適用後の文字数範囲の平均÷俊敏性1での平均）をミリ秒に丸めて固定する。文字数範囲はそのステージと武器の設定を使う。素手はチュートリアル全単語の平均文字数を基準とし、俊敏性で短縮した平均の下限を1文字とする。
- 入力した単語の長さやローマ字表記、ステージ途中の能力値変更では時間を変えない。チュートリアルの素手→木の枝の切り替えにも、開始時に計算した時間を使う。
- 通常攻撃はクールタイム終了まで待機し、その間は次の単語を非表示にする。残り時間は入力欄下部のバーで表示。キーボードの先行入力は終了後に反映し、フリックのキーは終了時に再び有効になる。敵の被弾待機はクールタイムを超えない。
- 双剣は選択中の敵1体を攻撃する。1単語につき1コンボ。撃破演出中・処理中の敵を重ねて攻撃しない。
- 強撃は従来どおり、スキルゲージが満タンで敵の被弾処理が終わっていれば使用できる。
- 双剣は2-2クリアで獲得し、装備画面から2-3へ進める。2-1に武器報酬はない。
- 旧短剣の装備は所持済みの鉄の剣に戻す。旧2-2クリア記録には双剣を補い、経験値・成長値・クリア記録は維持する。
- イラストとプロンプト: [双剣の制作記録](../assets/player/dual-blades-generation.md)。

## 片手剣と盾

- 3-1「キノコの森」の初回クリアで獲得し、装備画面で選ぶ。既存の3-1クリア記録にも補い、経験値・成長値・現在の装備は維持する。
- 片手に剣、もう片手に盾。Spaceを押している間だけ盾を構え、近接・胞子攻撃のダメージを0にする。ガード成功時はコンボ・連続成功・ノーダメージ判定を維持し、光と金属音を出す。
- ガード中は通常入力と強撃を停止する。途中まで入力した単語は残し、先行入力のキューはガード開始時に消去する。攻撃クールタイムは継続する。
- 片手剣の強撃はShift＋Space、または強撃ボタンで発動。他の武器はSpaceのまま。
- タッチ操作はガードボタンを押している間だけ有効。ボタン外で離しても解除し、画面を離れる・非表示・中断・終了・再開始でも解除する。
- 操作と演出は `src/app/guard.js`、軽減率は `src/config/weapons.js` の `guardDamageMultiplier`。
