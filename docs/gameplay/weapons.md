# 武器と攻撃

| 武器 | 俊敏性1でのクールタイム | 通常攻撃の対象 | 入力・威力 |
| --- | --- | --- | --- |
| 木の枝 | 0.22秒 | 1体 | 2〜3文字、攻撃力×0.2 |
| 鉄の剣 | 0.7秒 | 1体 | 通常の短い単語、攻撃力×1 |
| 大剣 | 1.5秒 | 1体 | 基本12〜20文字、溜めにより最大×4。未入力時はガード可 |
| 双剣 | 0.2秒 | 1体 | 基本2〜4文字、×0.6（整数に丸め最低1）、次の単語を予告 |
| 片手剣 | 0.7秒 | 1体 | 鉄の剣と同じ文字数・威力、盾でガード可能 |
| 素手 | 0.48秒 | 1体 | チュートリアルの1〜2文字 |

- `src/config/weapons.js` の `attackCooldownMs` と `attackTargets` で武器ごとに設定する。敵の被弾演出 `attackRecoveryMs` と攻撃アニメーション `attackAnimationMs` は独立している。
- ステージ開始時に、武器の基準時間×（俊敏性適用後の文字数範囲の平均÷俊敏性1での平均）をミリ秒に丸めて固定する。文字数範囲はそのステージと武器の設定を使う。素手はチュートリアル全単語の平均文字数を基準とし、俊敏性で短縮した平均の下限を1文字とする。
- 入力した単語の長さやローマ字表記、ステージ途中の能力値変更では時間を変えない。チュートリアルの素手→木の枝の切り替えにも、開始時に計算した時間を使う。
- 通常攻撃はクールタイム終了まで待機し、その間は入力対象の単語を非表示にする（双剣の予告は表示）。空欄でも行の高さを保ち、入力完了で画面やキーボードが伸び縮みしないようにする。残り時間は入力欄下部のバーで表示。単語が非表示の間のキー入力は破棄し、前の単語の末尾や長押しが次の単語のミスにならないようにする。キーの自動リピートは文字入力として扱わず、同じ文字を別々に押す入力は受け付ける。フリックのキーは終了時に再び有効になる。敵の被弾待機はクールタイムを超えない。
- 双剣は選択中の敵1体を攻撃する。1単語につき1コンボ。撃破演出中・処理中の敵を重ねて攻撃しない。
- 強撃は従来どおり、スキルゲージが満タンで敵の被弾処理が終わっていれば使用できる。
- 双剣は2-2クリアで獲得し、装備画面から2-3へ進める。2-1に武器報酬はない。
- 旧短剣の装備は所持済みの鉄の剣に戻す。旧2-2クリア記録には双剣を補い、経験値・成長値・クリア記録は維持する。
- イラストとプロンプト: [双剣の制作記録](../assets/player/dual-blades-generation.md)。

## 片手剣と盾

- 3-1「キノコの森」の初回クリアで獲得し、装備画面で選ぶ。既存の3-1クリア記録にも補い、経験値・成長値・現在の装備は維持する。
- 片手に剣、もう片手に盾。Spaceを押している間だけ盾を構え、近接・胞子攻撃で受けるダメージを本来の4分の1にする。端数は切り上げ、最低1ダメージを受ける。ガード成功時も被弾としてコンボ・連続成功・ノーダメージ判定をリセットする。成功時の光と金属音は維持する。
- ガード中は通常入力とスキルを停止する。途中まで入力した単語は残し、先行入力のキューはガード開始時に消去する。攻撃クールタイムは継続する。
- 全てのスキルはEnter、またはそれぞれのスキルボタンで発動。Spaceは片手剣・大剣のガード専用。
- タッチ操作はガードボタンを押している間だけ有効。ボタン外で離しても解除し、画面を離れる・非表示・中断・終了・再開始でも解除する。
- 操作と演出は `src/app/guard.js`、軽減率は `src/config/weapons.js` の `guardDamageMultiplier`。
- [画像と生成プロンプト](../assets/player/sword-shield-generation.md)。

## 大剣のガード

- Spaceまたはガードボタンを押している間、大剣で攻撃を受け、受けるダメージを本来の4分の1にする。端数は切り上げ、最低1ダメージ。被弾によるコンボ・ノーダメージ判定の扱いは片手剣と同じ。
- 1文字でも入力中の単語がある間はガード不可。フリックの確定待ちかなや先行入力も含む。別の敵を選んでも途中入力が残っていれば不可。
- 全ての入力を消した後、または単語を完成させて攻撃した後はガードできる。攻撃後のクールタイムも継続し、入力可能な場面で先行入力が残っている場合はガードを開始しない。
- ガード中は通常入力・スキルを停止する。強撃はEnterまたは強撃ボタンで使う。
- [大剣のガード画像と生成プロンプト](../assets/player/greatsword-guard-generation.md)。

## 戦闘フィードバック

- ガード成功は盾形の閃光、青白と金色の二重衝撃輪、放射状の火花、短い「ガード成功」表示と金属音で伝える。軽減後のダメージ数値は青く表示し、通常被弾の赤い画面効果は出さない。
- 通常被弾は赤い画面縁、主人公の点滅、赤いダメージ数値で表示する。
- ミスタイプは入力欄だけを黄色く光らせて横に揺らす。HPや被ダメージ演出には影響しない。
- ダメージ数値は650ms、ガードの衝撃は480msで消える。連続被弾では演出を再開し、画面移動・再開始・戦闘終了では消去する。動きを減らす設定では揺れと点滅を抑える。
- ダメージ表示は `src/app/battleFeedback.js`、ガード衝撃は `src/app/guard.js`、ミス表示は `src/app/game.js`。画像の追加ダウンロードは不要。

## 双剣の次単語予告

- 双剣装備中の戦闘だけ、入力中の単語の右側に「次：意味　入力する単語」を表示する。PCはローマ字、フリックはひらがなで表示する。
- 次の単語は事前に予約し、入力中に抽選し直さない。同じ敵への次の攻撃だけでなく、撃破時の次の敵にも予告を引き継ぐ。同時出現済みの次の敵がいる場合はその単語を表示する。最後の敵を倒せる状態では予告を隠す。
- 予告は攻撃クールタイム中も見えるが、入力は従来どおり待ち時間終了後から受け付ける。他の武器・メニュー・終了後には表示しない。
- 予告処理は `src/app/dualBladePreview.js`。文字数、威力、クールタイムと画像の読み込み範囲は従来どおり。

## 装備画面

- 一覧の武器を選ぶと、右側に装備姿と特徴を表示する。携帯幅では詳細を一覧の下に表示する。
- 選択だけでは装備もセーブも変更せず、詳細の下の「装備する」を押して確定する。現在装備中の武器では「装備中」と表示する。
- 報酬武器の案内と次ステージへのボタンは、実際に装備を確定するまで完了扱いにしない。
- 画像は選んだ武器の分だけ読み込む。失敗時は再読み込み可能。古い読み込みが後から完了しても、選び直した武器の画像を上書きしない。
- 鉄の剣のスキルは最大体力30％を回復する「癒しの光」。ゲージの増加量は他の武器の半分。

- 双剣のスキルは「時止め」。5秒間は敵の行動を止め、撃破後に現れる敵にも残りの効果時間を引き継ぐ。

- 片手剣のスキルは「戦意高揚」。8秒間、通常攻撃の威力が1.5倍になり、発動中もガードできる。
