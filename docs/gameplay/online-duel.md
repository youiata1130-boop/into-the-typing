# オンライン対戦

タイトルの「オンライン対戦」から名前を入力し、「部屋をつくる」で表示される8桁の部屋番号を相手に伝える。相手は番号を入力して「参加する」。双方が「準備完了にする」を押すと3秒のカウントダウン後に開始する。部屋は2人限定で、3人目は参加できない。

待機中とカウントダウン中は、自分・相手の問題文と入力文字、相手の文字数、双剣の次問予告を表示しない。戦闘開始と同時に各自の最初の問題を表示する。NPC戦と再戦も同じタイミングで表示し、開始前の入力は受け付けない。

部屋を作る側が「シンプル」「武器対戦」を選ぶ。参加側には部屋のモードが自動で反映される。武器対戦では準備中に双方が自分の武器を選択でき、武器を変更すると双方の準備完了が解除される。カウントダウン以降は変更できない。

両モードで部屋の作成者が「HPハンデ」を設定できる。比率は「なし（1：1）」、1：1.1、1：1.2、1：1.3、1：1.4、1：1.5、1：2、1：2.5、1：3。「HPを増やす人」でどちらのプレイヤーを増やすか指定する。基準HPは1,000で、選んだ側だけ初期HP・最大HPが1,100〜3,000になる。準備中は双方に設定とHPを表示し、作成者が変更すると双方の準備完了を解除する。変更前の条件で送られた古い準備完了も無効。開始後は変更できない。

## 対戦ルール

- ハンデなしでは双方の体力は1,000。シンプルは1問40ダメージ、武器対戦は入力文字数に応じて威力が変わる。HPハンデは攻撃力や出題・制限時間に影響しない。冒険のレベル・能力・装備による差はつけない。
- シンプルは通常の日本語問題からローマ字10〜16文字の63問を使用し、双方に同じ順序で出題する。武器対戦は共通のシャッフル順から各自の武器に合う長さの問題を選ぶ。同じ武器では同じ順序、異なる武器では別の問題になる。入力表示と判定、双剣の次問予告は各自の問題を使う。
- シンプルは1問につき最低2秒の入力時間を設ける。早く入力できた場合は入力完了の表示を保持し、2秒経過時に攻撃する。HP1,000の相手を倒すには25回の攻撃が必要で、最短でも50秒かかる。武器対戦は文字数に比例する入力の最低時間と予備動作を設ける。予備動作中は相手の入力欄と武器の枠がオレンジに光る。
- PCはローマ字、スマホはゲーム内フリック入力。入力済み文字・残り文字・文字数・進捗バーを相手へ逐次反映する。濁点や小文字の変更途中は正しく確定した部分までを送信する。
- 入力ミスで体力を減らさない。未完了の文字はBackspaceまたは⌫で戻せる。
- 体力が0になるか3分経過で終了。時間切れは残り体力の多い側が勝利、同体力または同時に体力0なら引き分け。HPハンデありでも割合ではなく残りHPの数値を比較する。
- 再戦には双方の「もう一度対戦」が必要。体力・出題順・入力・防御状態・防御コスト・試合IDをリセットし、モード・武器・HPハンデは引き継ぐ。体力は各自の最大HPまで回復する。
- 切断や相手の退出は対戦中止とし、勝利扱いにしない。12秒間応答がない場合も中止する。再接続は新しい部屋で行う。
- 冒険の経験値・クリア記録・装備・セーブデータには変更を加えない。

## 武器対戦

冒険での所持状況によらず、次の4種類から選べる。木の枝・素手は選択肢にも通信上の許可リストにも含めない。スキルは全武器で無効とし、スキルボタンを表示せず、Enterやスキルの通信で発動しない。

| 武器 | 問題の長さ（最短ローマ字入力） | 対戦中の特徴 |
| --- | --- | --- |
| 鉄の剣 | 2〜8文字・154問 | カウンター。受付0.2秒、再使用まで0.6秒。成功時は被ダメージ0、最大20を相手に返す。 |
| 大剣 | 12〜20文字・32問 | 入力に合わせて3段階の溜め姿勢。未入力または入力完了時にガードできる。入力途中・かなの修正待ち中は不可。 |
| 双剣 | 2〜4文字・39問 | 短い問題で素早く連撃し、次の問題を予告する。ガード・カウンターは使わない。 |
| 片手剣 | 2〜8文字・154問 | 入力途中でもガードできる。解除後は途中の入力から再開する。 |

フリックも同じ単語をかなで出題する。問題選びの長さは最短のローマ字入力で測り、威力と攻撃間隔は実際に完成した入力（ローマ字またはかな）の文字数で計算する。

PCではSpaceまたは↓、スマホでは入力欄の「ガード」「カウンター」ボタンを使う。ガードは押している間だけ有効で、1回受け止めた時点でも解除する。通常ガードは被ダメージ1/2、開始から0.2秒以内のジャストガードは1/4。ガード中とカウンター受付中は新しい文字を入力できない。すでに予備動作へ入った攻撃はそのまま発生する。画面を離れた場合もガードを解除する。

通常ガードは青い盾、ジャストガードは金色の大きな二重の盾と放射状の光、カウンターは紫の斬撃で表示する。成功の文字は表示しない。

### バランス

武器対戦の1文字あたりの威力は4、入力の最低時間は0.2秒、予備動作は0.04秒。4文字なら威力16・最低入力0.8秒・予備動作0.16秒、16文字なら威力64・最低入力3.2秒・予備動作0.64秒になる。短文は手数、長文は一撃の威力に特徴を持たせ、同じ入力速度での理論上の継続火力をそろえる。冒険のダメージ倍率や成長補正・スキルは適用しない。

防御が一方的な火力差にならないよう、成功時には次の攻撃力を前借りする。画面の「防御コスト」が残っている間は再防御できず、以後の攻撃の威力でコストを支払い、残りが攻撃ダメージになる。支払いきれなければ次の攻撃へ繰り越す。以下は威力40の攻撃で受け払いする例。

- 通常ガードで40を20に減らすとコスト20。次の攻撃は20ダメージ。
- ジャストガードで40を10に減らすとコスト30。次の攻撃は10ダメージ。
- カウンターで40を防いで20を返すとコスト60。次の攻撃は0、その次は20ダメージ。
- 時間切れ・体力0で終了する際の未払い分は自分の残り体力から差し引いて勝敗を判定する。終了直前の防御だけで差がつくことを防ぐ。

防御で防いだ分と反撃した分はコストと相殺される。自動検証ではハンデなしの16組み合わせ × 入力速度3種類（2・5・10文字/秒）× ローマ字/かな × 防御あり/なし × 問題順3種類の576試合で、同じ武器同士は引き分け、異なる武器同士でも終了時の残りHP差が80以内に収まることを確認する。異なる長さの問題は攻撃が成立するタイミングも異なるため、全組み合わせでの引き分けや人同士の勝率50%は保証しない。

## NPC戦

タイトルの「NPC戦」から、自分の武器と次の3項目を選び、「対戦開始」で3秒のカウントダウン後に開始する。部屋番号や対戦相手の接続は不要。NPC戦ではPeerJSを読み込まず、対戦サービスへの通信も行わない。

- NPCの武器：鉄の剣・大剣・双剣・片手剣。木の枝・素手は使用しない。
- NPCのHP：500・1,000・1,500・2,000・2,500・3,000。自分のHPは1,000。
- NPCの入力速度：1・2・3・4・6文字/秒。初期値は3文字/秒。

武器対戦と同じ武器別の問題、文字数に応じた威力・最低入力時間・予備動作、ガード・カウンター、防御コスト、3分の制限時間を使い、スキルは使えない。NPCはPCではローマ字、フリックではかなを1文字ずつ入力し、進捗バーにも反映する。指定速度は入力できる間の文字数で、ガード・カウンター中や入力完了後の待機時間には入力しない。

NPCは相手の攻撃の予備動作を見て、一定の確率で0.25秒後に防御を試みる。大剣の入力途中ガード禁止や防御コストなど、人と同じ制限に従う。速度設定で攻撃力や防御成功率を上げることはしない。

別タブや別画面へ移ってページが非表示になった間は、カウントダウン・制限時間・攻撃・入力を停止する。復帰時に溜まった文字をまとめて入力しない。退出するとNPCの更新を停止する。

終了後の「もう一度対戦」は同じ設定で体力・入力・出題順をリセットする。「設定を変える」から武器・HP・速度を選び直せる。オンラインのHPハンデはNPC戦に適用せず、それぞれの設定を保持する。冒険のセーブ・経験値・クリア記録は変えない。

## 通信と公開環境

GitHub Pagesの既存URLで動作する。PeerJS 1.5.5を同梱し、部屋の作成または参加時だけ読み込む。ソロプレイや対戦メニューを開いただけではPeerJSサービスに接続しない。

接続の仲介はPeerServer Cloudを使用し、対戦データはWebRTC DataChannelで交換する。公開STUNを使用し、ライブラリに残っている廃止済みTURNホストは接続先から除外する。カメラ・マイクへのアクセス、アカウント作成、保存済みの冒険データの送信は行わない。相手には入力した対戦名と対戦情報を送る。

PeerServer Cloudと通信環境に依存する。[運営元は無料TURNサービスを終了している](https://github.com/orgs/peers/discussions/1172)。2026-10-25の中継強制テストでも接続できず、既定TURNホストのDNSレコードがないことを確認した。現状は直接接続できるネットワークで利用でき、一部の携帯回線や社内ネットワークなど、TURNが必要な組み合わせは接続できない。これらへの対応には利用者所有の中継サービスの設定が必要。接続できない場合はゲーム内にエラーを表示して再試行できる。接続サービスの停止や大規模利用に対する稼働保証はない。

部屋を作ったブラウザーが体力・入力判定・攻撃間隔・残り時間・勝敗を管理する。参加側からの体力やダメージ指定を受け付けず、試合ID・問題番号・入力連番・文字列を検証する。古い試合の入力や重複攻撃は無効。両端末の時計が異なっていても参加側の時刻で勝敗を決めない。改造したホストを防ぐ専用サーバー型の不正対策やランキングは備えないため、友達同士の対戦を対象とする。

武器・防御操作もホストで検証し、別武器の防御、入力中の大剣ガード、コスト未払い、連番の再送を受け付けない。HPハンデは許可した9段階と対象2人だけを認め、受信した最大HPが設定と一致することも確認する。時計は共有せず、攻撃・カウンターの残り時間だけを送る。各プレイヤーの武器に合った問題と予備動作の上限も確認する。プロトコルはv4で、更新前のクライアントとは接続せず再読み込みを案内する。

## 実装

- `src/online/duel.js`: 共通の入力判定、体力、攻撃、勝敗、スナップショット検証。
- `src/online/connection.js`: PeerJSの遅延読み込み、部屋番号、接続エラー。
- `src/online/play.js`: 部屋管理、通信、対戦画面、フリック、退出・再戦。
- `src/online/npc.js`: NPC設定、文字入力の進行、防御判断、一時停止からの復帰。
- `tests/integration/battle/onlineDuel.test.mjs`: 開始条件、進捗、攻撃間隔、25回の攻撃、同時決着、時間切れ、かな入力、不正・古い通信、退出。
- `tests/integration/battle/onlineWeapons.test.mjs`: 武器の許可リスト、ガード・カウンターの境界、入力制限、防御コスト、全武器の収支、再戦、スキル無効、退出時の解除。
- `tests/integration/battle/onlineHandicap.test.mjs`: HP比率・対象・上限、設定の共有と固定、古い準備完了の拒否、ダメージと勝敗、再戦時の回復。
- `tests/integration/battle/npcDuel.test.mjs`: NPCの武器・HP・入力速度、攻撃と防御、通信なしでの操作、一時停止、再戦、退出。
