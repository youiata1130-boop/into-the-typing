# オンライン対戦

タイトルの「オンライン対戦」から名前を入力し、「部屋をつくる」で表示される8桁の部屋番号を相手に伝える。相手は番号を入力して「参加する」。双方が「準備完了にする」を押すと3秒のカウントダウン後に開始する。部屋は2人限定で、3人目は参加できない。

## 対戦ルール

- 双方の体力は1,000、1問正解で40ダメージ。冒険のレベル・能力・装備による差はつけない。
- 通常の日本語問題からローマ字10〜16文字の45問を使用する。1試合ごとに順序をシャッフルし、双方に同じ順序で出題する。
- 1問につき最低2秒の入力時間を設ける。早く入力できた場合は入力完了の表示を保持し、2秒経過時に攻撃する。相手を倒すには25回の攻撃が必要で、最短でも50秒かかる。
- PCはローマ字、スマホはゲーム内フリック入力。入力済み文字・残り文字・文字数・進捗バーを相手へ逐次反映する。濁点や小文字の変更途中は正しく確定した部分までを送信する。
- 入力ミスで体力を減らさない。未完了の文字はBackspaceまたは⌫で戻せる。
- 体力が0になるか3分経過で終了。時間切れは残り体力の多い側が勝利、同体力または同時に体力0なら引き分け。
- 再戦には双方の「もう一度対戦」が必要。体力・出題順・入力・試合IDをリセットする。
- 切断や相手の退出は対戦中止とし、勝利扱いにしない。12秒間応答がない場合も中止する。再接続は新しい部屋で行う。
- 冒険の経験値・クリア記録・装備・セーブデータには変更を加えない。

## 通信と公開環境

GitHub Pagesの既存URLで動作する。PeerJS 1.5.5を同梱し、部屋の作成または参加時だけ読み込む。ソロプレイや対戦メニューを開いただけではPeerJSサービスに接続しない。

接続の仲介はPeerServer Cloudを使用し、対戦データはWebRTC DataChannelで交換する。公開STUNを使用し、ライブラリに残っている廃止済みTURNホストは接続先から除外する。カメラ・マイクへのアクセス、アカウント作成、保存済みの冒険データの送信は行わない。相手には入力した対戦名と対戦情報を送る。

PeerServer Cloudと通信環境に依存する。[運営元は無料TURNサービスを終了している](https://github.com/orgs/peers/discussions/1172)。2026-10-25の中継強制テストでも接続できず、既定TURNホストのDNSレコードがないことを確認した。現状は直接接続できるネットワークで利用でき、一部の携帯回線や社内ネットワークなど、TURNが必要な組み合わせは接続できない。これらへの対応には利用者所有の中継サービスの設定が必要。接続できない場合はゲーム内にエラーを表示して再試行できる。接続サービスの停止や大規模利用に対する稼働保証はない。

部屋を作ったブラウザーが体力・入力判定・攻撃間隔・残り時間・勝敗を管理する。参加側からの体力やダメージ指定を受け付けず、試合ID・問題番号・入力連番・文字列を検証する。古い試合の入力や重複攻撃は無効。両端末の時計が異なっていても参加側の時刻で勝敗を決めない。改造したホストを防ぐ専用サーバー型の不正対策やランキングは備えないため、友達同士の対戦を対象とする。

## 実装

- `src/online/duel.js`: 共通の入力判定、体力、攻撃、勝敗、スナップショット検証。
- `src/online/connection.js`: PeerJSの遅延読み込み、部屋番号、接続エラー。
- `src/online/play.js`: 部屋管理、通信、対戦画面、フリック、退出・再戦。
- `tests/integration/battle/onlineDuel.test.mjs`: 開始条件、進捗、攻撃間隔、25回の攻撃、同時決着、時間切れ、かな入力、不正・古い通信、退出。
