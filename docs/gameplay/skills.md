# 戦闘スキル

- 鉄の剣は「癒しの光」。最大体力の30％（端数切り上げ）を回復し、上限を超えない。体力満タン時は発動せず、ゲージを消費しない。
- 大剣は「強撃」。生存している敵全体に、装備武器の最大威力の通常攻撃×3のダメージを与える。
- 大剣では入力途中の溜め具合やミスに左右されず、最大倍率で計算する。攻撃力2なら大剣24ダメージ。
- 正しい新規入力1文字（内部のローマ字換算）につき、鉄の剣はゲージ2、他の武器は4。上限100で、鉄の剣は50文字、他は25文字で満タン。ミスでは減らず、削除・再入力で同じ文字から再充填できない。
- 満タンでEnter、またはスキル名のボタンを押すと発動し、ゲージを全消費。長押し・連打・攻撃解決中は重複発動しない。ガード中は発動できない。
- 木の枝・素手装備中、チュートリアルと会話中は利用不可。木の枝ではゲージを増やさず、スキル欄も表示しない。戦闘開始・再開始でゲージをリセットし、ゲージはセーブしない。
- 強撃は斬撃演出と効果音を使い、撃破・経験値・クリアは通常の戦闘処理に接続する。
- 回復は緑の光、足元の光輪、上昇する十字の粒子と実際の回復量を表示し、専用の音を鳴らす。発動中650msは入力を止めるが、敵の攻撃や溜めは止めない。敵のHP・単語・位置を変更しない。演出は900msで消え、画面移動や再開始で解除する。

## 追加・調整する場所

- `src/config/skills.js`: スキル名、対象、効果一覧、倍率、演出待ち時間、共通ゲージ設定。
- `src/app/skills.js`: 対象選択、効果種類ごとのハンドラー、スキルゲージ表示。新しい効果は `skillEffectHandlers` に追加する。
- `src/app/game.js`: 発動条件、ゲージ消費、入力抑止、戦闘への復帰を共通管理。既存コードとの整合のため内部名 `specialGauge` / `useSpecialMove` を継続。
- 現在の選択は `state.skillId`。初期値は `power_strike`。スキルを増やした段階で選択画面や保存項目を追加する。

## 双剣の時止め

- 双剣のスキルは「時止め」。ゲージ100を消費して5秒間、全ての敵の移動・溜め・攻撃を停止する。1文字でゲージ4増える従来の速さを維持する。
- 敵ごとではなく戦闘全体の効果として管理する。敵を倒しても終了せず、残り時間中に現れた敵やボスにも停止がかかる。新しい敵が出ても5秒にリセットしない。
- 自分は停止中も入力・通常攻撃ができる。敵のHPや単語はスキルで変更しない。停止中の再発動ではゲージを消費せず、延長もしない。
- 効果終了時は停止した位置・溜め時間・近接攻撃の残り待ち時間から再開し、停止中の経過をまとめて処理しない。再開始・離脱・戦闘終了時は解除する。
- 敵を青白く表示し、一時停止マークと「時止め中」を表示する。制御は `src/app/enemyActionStop.js`。

## 片手剣の戦意高揚

- ゲージ100を消費し、8秒間、通常攻撃の威力を1.5倍にする。端数処理は通常攻撃と同じ。能力の振り分け値や保存データは変更しない。
- Enterまたはスキルボタンで発動し、直後から入力・攻撃・ガードを続けられる。即時ダメージや敵の溜め解除はない。ガードの被ダメージ1/4は変わらない。
- 効果は敵を倒しても残り時間だけ継続し、重ねがけ・延長は不可。効果終了・戦闘終了・離脱・再開始で解除する。
- 金色のオーラと「攻撃力1.5倍」で表示する。制御は `src/app/attackBoost.js`。
