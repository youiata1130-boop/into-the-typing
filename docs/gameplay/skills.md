# 戦闘スキル

- 初期スキルは「強撃」1種類。生存している敵全体に、装備武器の最大威力の通常攻撃×3のダメージを与える。
- 大剣では入力途中の溜め具合やミスに左右されず、最大倍率で計算する。攻撃力2なら木の枝1.2、鉄の剣6、大剣24ダメージ。
- 正しい新規入力1文字（内部のローマ字換算）につきゲージ4、上限100。25文字で満タン。ミスでは減らず、削除・再入力で同じ文字から再充填できない。
- 満タンでSpace（片手剣はShift＋Space）、または「強撃」ボタンを押すと発動し、ゲージを全消費。長押し・連打・攻撃解決中は重複発動しない。ガード中は発動できない。
- チュートリアルと会話中は利用不可。戦闘開始・再開始でゲージをリセットし、ゲージはセーブしない。
- 既存の斬撃演出と効果音を使い、撃破・経験値・クリアは通常の戦闘処理に接続する。

## 追加・調整する場所

- `src/config/skills.js`: スキル名、対象、効果一覧、倍率、演出待ち時間、共通ゲージ設定。
- `src/app/skills.js`: 対象選択、効果種類ごとのハンドラー、スキルゲージ表示。新しい効果は `skillEffectHandlers` に追加する。
- `src/app/game.js`: 発動条件、ゲージ消費、入力抑止、戦闘への復帰を共通管理。既存コードとの整合のため内部名 `specialGauge` / `useSpecialMove` を継続。
- 現在の選択は `state.skillId`。初期値は `power_strike`。スキルを増やした段階で選択画面や保存項目を追加する。
