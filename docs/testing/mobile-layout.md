# スマートフォン戦闘画面の確認（2026-09-08）

## 変更範囲

- 戦闘中のレベル・経験値表示を非表示にし、戻るボタンを背景に重ねた。ステータス画面、クリア結果、成長計算、保存形式は維持。
- visualViewport の高さ・幅・オフセット、resize / scroll / orientationchange と ResizeObserver で可視領域に追随。
- キーボード表示時はお題と44pxの入力欄を横にまとめる。長いお題は折り返す。通常配置への復帰にも対応。
- 空きスペースとキャラクターの足元の余白を先に調整し、収まらない場合だけ画像を縮小。HPは画像とは別に読みやすい高さを維持。
- 入力欄は固定したまま値だけを更新。開始・会話の「次」・お題のタップだけでフォーカスし、自動処理はキーボードを再表示しない。

## 自動確認済み

- `npm run check`：18ファイルの構文確認。
- `npm test`：40件成功。既存の成長、保存、ストーリー、大剣の判定を含む。
- 日本語の変換途中、濁点、半濁点、小文字、確定イベントの重複、古いお題の確定、改行の処理を確認。
- 戻る・意図的なフォーカス解除・開始直後のキーボード終了を、自動処理が妨げないことを確認。

- 上記の画面で主人公・敵の画像、両者のHP、お題、入力欄が同時に収まり、入力エリアで隠れないことを矩形の比較と画像で確認。
- visualViewportを小さくする再現と、ブラウザー自体のサイズ変更の両方を確認。可視領域の上方向のずれ、縦横の回転、通常サイズへの復帰を確認。
- 戻るボタンは88 × 48px。主人公のHPとの重なりなし。戦闘中のレベル表示とヘッダーの占有領域なし。
- 最初の3回の素手攻撃と木の枝を受け取った後の12回の入力を、入力欄の再タップなしで確認。
- 木の枝でステージ全体を95回の確定入力でクリア。入力欄の再タップ・blur・戦闘中のreadonly/disabled変更はいずれも0回で、同じDOM要素を維持。
- クリア時は110 EXP、Lv.3、2 SP。v2のセーブデータは従来の形式で保存された。
- 長いお題と大剣の振りかぶり、PCでの通常のローマ字入力・連続攻撃も確認。
- 回転時に敵が以前の座標からアニメーションして一時的にはみ出す問題を修正し、再確認。

iPhone / Androidの実機、実際の日本語キーボードの開閉・候補欄、端末固有の変換イベント、ノッチ・ホームインジケーターの表示は未確認。キーボードの描画や実機固有の挙動は、ブラウザー上の再現テストだけでは保証していない。
