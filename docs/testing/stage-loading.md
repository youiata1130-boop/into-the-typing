# 画像の段階読み込み

- 起動時は共通背景1枚だけを取得する（約1.4MB）。
- 地図は選んだ地域の画像、ホーム・装備・ステータスは共通の室内背景を初めて開く時に取得する。
- ステージ開始時に、そのステージの背景、登場する敵の全動作、装備中の武器、報酬イラストを取得する。最初のステージでは必要なプロローグ、素手、木の枝も取得する。
- ダウンロードと画像のデコードが終わるまで読み込み画面を表示し、戦闘時間を進めない。失敗・45秒のタイムアウト時は再試行でき、成功済みの画像は取得し直さない。
- 取得済みの画像は画面移動・ステージ変更・再挑戦で共有する。武器を変えた場合は次のステージ開始時に必要な画像を追加する。
- 隠れたHTML画像とSVG画像には初期の参照先を置かず、表示する時に設定する。全画像一覧を作る `collectGameImageSources()` は検証用で、ダウンロードを開始しない。

検証: 286件のテストと構文チェック。実際のブラウザーで1280×900、390×844、320×500、844×390の通信を確認し、起動時1枚のみ、地図・ステージごとの追加取得、失敗後の再試行、再挑戦時の再利用を確認。新規プレイヤーのプロローグ全3場面と最初の素手戦闘への移行も確認した。
