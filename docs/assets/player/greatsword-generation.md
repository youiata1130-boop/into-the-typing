# Greatsword Player Art

All sprites documented below were created with the built-in ImageGen tool in `stylized-concept` mode. No existing project image was sent to the image-generation service; each frame was generated from text only.

## Charge animation sequence

The existing transparent sprites now form a three-pose sequence: low guard (charge/frame_01), raised blade (idle/frame_01), and overhead wind-up (attack/frame_01). The first and second thirds of charge advance the pose. Each correct character builds charge; a miss resets the pose and aura, keeping the correct typing prefix. Subsequent letters rebuild charge across the remaining prompt. No images were regenerated or modified for this animation change.
